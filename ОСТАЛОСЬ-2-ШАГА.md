# Репозиторий Teacherdesk создан — осталось 2 шага

Репозиторий получился **приватным** (галочка «Keep this code private» в GitHub
Desktop стоит по умолчанию). Бесплатный сайт GitHub Pages работает только с
публичными репозиториями, поэтому сначала откроем его, потом включим сайт.
Бояться нечего: ваших данных в коде нет — записи журнала хранятся только на
ваших устройствах, а в репозитории лежит пустое приложение.

## Шаг 1. Сделать репозиторий публичным

1. Откройте **github.com/mpz34-stack/Teacherdesk** (войдя в свой аккаунт)
2. Вкладка **Settings** (шестерёнка, справа сверху)
3. Прокрутите страницу в самый низ до красной зоны **Danger Zone**
4. Строка **Change repository visibility** → кнопка **Change visibility** →
   **Change to public**
5. GitHub попросит подтвердить: нажмите «I want to make this repository public»,
   затем введите с клавиатуры `mpz34-stack/Teacherdesk` и подтвердите

## Шаг 2. Включить сайт

1. Там же в **Settings** → в левом меню пункт **Pages**
2. Раздел «Build and deployment»: Source = **Deploy from a branch**,
   Branch = **main**, папка **/ (root)** → **Save**
3. Подождите 1–2 минуты, обновите страницу — сверху появится адрес:

   **https://mpz34-stack.github.io/Teacherdesk/**

Это и есть журнал. На телефоне: открыть адрес → **iPhone (Safari)**:
«Поделиться» → «На экран “Домой”»; **Android (Chrome)**: меню ⋮ →
«Добавить на главный экран». После установки работает без интернета.

## Проверка: файлы на месте?

На главной странице репозитория должен быть виден список файлов:
`index.html`, `manifest.webmanifest`, `sw.js`, иконки, `README.md` и другие.

Если вместо списка — надпись «Quick setup» (репозиторий пуст), значит файлы не
загрузились. Тогда в GitHub Desktop: убедитесь, что открыт репозиторий
Teacherdesk и он смотрит на папку «github-репозиторий»; слева должны быть файлы
с галочками → внизу Summary: `Журнал репетитора 1.0` → **Commit to main** →
сверху **Push origin**.

## Обновления в будущем

Новый `index.html` положить в папку «github-репозиторий» → GitHub Desktop сам
увидит изменение → Summary → **Commit to main** → **Push origin**. Сайт
обновится сам за минуту-две, данные пользователей не пострадают.
