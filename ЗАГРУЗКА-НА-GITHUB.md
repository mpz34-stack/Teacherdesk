# Как загрузить эту папку на GitHub вручную (~5 минут)

Все файлы уже готовы — остались четыре шага на сайте github.com.

## 1. Создать репозиторий

1. Откройте **github.com/new** (войдите в свой аккаунт, если попросит)
2. Repository name: **tutor-journal**
3. Видимость: **Public** (бесплатный GitHub Pages работает только с публичными
   репозиториями; ваших данных в коде нет — они хранятся только на устройствах)
4. Галочку «Add a README file» **не** ставьте
5. Нажмите **Create repository**

## 2. Загрузить файлы

1. На странице нового репозитория нажмите ссылку **«uploading an existing file»**
   (или Add file → Upload files)
2. Перетащите в окно **все файлы из этой папки** (кроме этого файла-инструкции):
   index.html, manifest.webmanifest, sw.js, три иконки, README.md, DESIGN.md,
   BUILD_PROMPT.md, REVIEW.md, check.js, два скриншота
3. Внизу нажмите **Commit changes**

## 3. Включить сайт (GitHub Pages)

1. В репозитории: **Settings** → слева **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main**, папка **/ (root)** → **Save**
4. Через 1–2 минуты обновите страницу — сверху появится адрес вида
   `https://ваш-логин.github.io/tutor-journal/`

## 4. Поставить на телефон

Откройте этот адрес в браузере телефона:

- **iPhone (Safari):** «Поделиться» → **«На экран “Домой”»**
- **Android (Chrome):** меню ⋮ → **«Добавить на главный экран»**

Готово: иконка на экране, работает офлайн.

## Обновления в будущем

Изменился index.html → в репозитории Add file → Upload files → перетащить новый
файл → Commit. Pages пересоберётся сам за минуту-две. Данные пользователей при
обновлении не затрагиваются.
